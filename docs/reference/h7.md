# h7 library

The global `h7` table holds the engine's API. It is shared by every mod and by `exec` scripts.

Parameters called **class** take a class name (`"H7AdventureHero"` or `"MMH7Game.H7AdventureHero"`) or a class
object; **func** takes a function path (`"MMH7Game.H7Calendar.NextDay"`, optionally prefixed with `"Function "`)
or a function object.

## Engine

### h7.version

```lua
h7.version → string
```

The engine version, e.g. `"0.1.0"`. Use it to check for features your mod needs.

## Logging

All logging goes to `<Game>\H7ModEngine\logs\engine.log` (the previous run is kept in `engine.prev.log`). Each
line starts with a timestamp and the name of the mod that wrote it, or `[lua]` for code that runs outside any mod
(`exec` scripts).

### h7.log

```lua
h7.log(...)
print(...)
```

Writes its arguments, converted with `tostring` and separated by tabs, as one line:

```lua
h7.log("Hero", hero, "has", 12, "movement points")
-- [19:32:14.962] [MyMod] Hero	H7AdventureHero sce_sephinroth.TheWorld.PersistentLevel.H7AdventureHero_0	has	12	movement points
```

`print` is the same function.

### h7.warn

```lua
h7.warn(...)
```

Like [`h7.log`](#h7log), with the line prefixed `WARNING`.

### h7.error

```lua
h7.error(...)
```

Like [`h7.log`](#h7log), with the line prefixed `ERROR`. It only **logs**; it does not raise an error or stop
your code. To stop with an error, use Lua's `error("message")`.

## Finding objects

### h7.first

```lua
h7.first(class) → object | nil
```

The first live instance of `class` or one of its subclasses, or `nil` if there is none. Class default objects
(`Default__...`) and archetypes (templates stored in content packages) are skipped.

| Parameter | |
|---|---|
| `class` | Class name or class object |

**Errors:** `unknown class '<name>'` if a class name doesn't exist.

```lua
local controller = h7.first("H7AdventureController")
if controller then h7.log(controller:GetLocalPlayer(true):GetName()) end
```

"First" means lowest in the engine's object table, which usually but not always is the one created first. When
there can be several instances (heroes, players, armies), use [`h7.find_all`](#h7find_all) and pick the one you
want.

### h7.find_all

```lua
h7.find_all(class [, include_templates]) → { object, ... }
```

Every live instance of `class` or its subclasses, as a sequence (empty when there are none).

| Parameter | |
|---|---|
| `class` | Class name or class object |
| `include_templates` | `true` to include class default objects and archetypes. Default `false` |

**Errors:** `unknown class '<name>'`.

```lua
for _, hero in ipairs(h7.find_all("H7AdventureHero")) do
    h7.log(hero:GetName(), hero:GetLevel())
end

-- every creature archetype the game has loaded
local creatures = h7.find_all("H7Creature", true)
```

`find_all` scans the whole engine object table. Call it when you need it, not every frame,
and cache the result while it stays valid (until the next `map_loaded`, for objects in a map).

### h7.find

```lua
h7.find(path) → object | nil
```

The object with the given path name, or `nil`. The path may be prefixed with the object's class to tell apart
objects with the same path.

| Parameter | |
|---|---|
| `path` | `"Package.Outer.Name"`, or `"ClassName Package.Outer.Name"` |

```lua
local calendar_class = h7.find("Class MMH7Game.H7Calendar")
local next_day = h7.find("Function MMH7Game.H7Calendar.NextDay")
local pixie = h7.find("Creature_Pixie.A_CreaturePixie")   -- an archetype in a content package
```

`dumps\objects.txt` (written at startup) lists every object's path.

### h7.find_class

```lua
h7.find_class(name) → class | nil
```

The class called `name` (`"Package.Class"` or the bare `"Class"`), or `nil`.

```lua
local hero_class = h7.find_class("H7AdventureHero")
h7.log(hero_class:get_super())   -- Class MMH7Game.H7EditorHero
```

### h7.enum

```lua
h7.enum(name) → { [string] = integer }
```

A table mapping each name of the UnrealScript enum `name` to its numeric value (`0`, `1`, ...). Enum values read
from properties and function results are plain integers; use this table to compare them or pass them.

| Parameter | |
|---|---|
| `name` | The enum's name (`"EUnitType"`) or path (`"MMH7Game.AH7StructsAndEnumsNative.EUnitType"`) |

**Errors:** `unknown enum '<name>'`.

```lua
local UnitType = h7.enum("EUnitType")
if unit:GetEntityType() == UnitType.UNIT_HERO then ... end
```

## Reflection

### h7.properties

```lua
h7.properties(x) → { { name, type, owner, offset }, ... }
```

Every property of a class or struct, inherited ones included.

| Parameter | |
|---|---|
| `x` | A class or struct name; an object (lists its class); a class, struct or function object; or a struct reference |

| Field | |
|---|---|
| `name` | Property name, as used from Lua |
| `type` | The engine's property type, e.g. `IntProperty`, `ObjectProperty`, `ArrayProperty`, `StructProperty` |
| `owner` | The class or struct that declares it |
| `offset` | Byte offset inside the object or struct |

Passing a function object lists its parameters and local variables. Properties of types the engine doesn't
support are left out.

**Errors:** `unknown class/struct '<name>'`.

```lua
for _, p in ipairs(h7.properties("MMH7Game.H7Calendar")) do h7.log(p.owner, p.type, p.name) end
```

### h7.functions

```lua
h7.functions(x) → { { name, type, owner, flags }, ... }
```

Every function of a class (or struct), inherited ones included. `x` takes the same values as in
[`h7.properties`](#h7properties).

| Field | |
|---|---|
| `name` | Function name |
| `type` | The function object's class (`"Function"`) |
| `owner` | The class that declares it. A function overridden in a subclass appears once per declaring class |
| `flags` | The engine's function flags (bit field: `0x400` native, `0x800` event, `0x2000` static, ...) |

**Errors:** `unknown class/struct '<name>'`.

### h7.signature

```lua
h7.signature(func) → string
```

The function's declaration in UnrealScript syntax: `static` / `native` / `event` qualifiers, return type, full
path and parameters with `out` and `optional`.

**Errors:** `function '<path>' not found (use Package.Class.Function)`; `expected a Function object`.

```lua
h7.log(h7.signature("MMH7Game.H7GameProcessor.CalculateDamage"))
-- function void MMH7Game.H7GameProcessor.CalculateDamage(out H7CombatResult Result, int resultIdx, bool forecast)
```

Check the signature before hooking a function: `native` functions can be hooked but give the hook no arguments
and can't be blocked (see [h7.hook](#h7hook)).

### h7.to_table

```lua
h7.to_table(value) → table | value
```

A plain Lua copy of an engine value, independent of the engine:

| `value` | Result |
|---|---|
| Struct reference | Table of its fields |
| Array reference | Sequence of its elements |
| Object reference | Table of the object's properties |
| Anything else | `value` itself |

Structs and arrays inside are copied recursively; objects inside stay object references (they are not expanded,
since object graphs loop). Use it to log a value, or to keep hook arguments after the hook returns.

```lua
h7.hook_post("MMH7Game.H7GameProcessor.CalculateDamage", function(proc, args)
    last_result = h7.to_table(args.Result)    -- args.Result itself is invalid after the hook
end)
```

## Hooks

A hook runs a Lua function whenever a game function is called, from UnrealScript or from the engine's C++ code.
See [Hooks](../API.md#hooks) in the guide for what hooks see and how to keep them fast.

### h7.hook

```lua
h7.hook(func, fn [, when]) → id
```

Adds a hook on `func` and returns its id (an integer, for [`h7.unhook`](#h7unhook)).

| Parameter | |
|---|---|
| `func` | Function path or function object |
| `fn` | The hook function, see below |
| `when` | `"pre"` (default): before the function runs; `"post"`: after it, like [`h7.hook_post`](#h7hook_post) |

A pre-hook is called as `fn(self, args)`:

| Argument | |
|---|---|
| `self` | The object the function was called on |
| `args` | The function's parameters by name, readable and writable (a [struct reference](objects.md#hook-arguments)). `nil` for native functions |

Return `true` (the boolean) to **block** the call: the original function doesn't run and its caller gets a zero
return value (`0`, `false`, `""`, `None`). Post-hooks still run. Any other return value lets the call proceed.
Changing `args` changes what the function receives.

**Errors:** the function isn't found; `could not hook <path>`.

```lua
-- No hero may visit obelisks
h7.hook("MMH7Game.H7Obelisk.OnVisit", function(obelisk, args)
    return true
end)
```

Errors inside `fn` are logged with a stack trace and the call continues as if the hook had returned nothing;
the hook stays installed.

Hooks on **native** functions (`native` in [`h7.signature`](#h7signature)) receive `args = nil` and can't
block; the engine logs a note when you add a pre-hook to one. Latent and iterator functions only report calls
made from C++.

### h7.hook_post

```lua
h7.hook_post(func, fn) → id
```

Adds a hook that runs after `func` has run. Same as `h7.hook(func, fn, "post")`. `fn` is called as
`fn(self, args, result)`:

| Argument | |
|---|---|
| `self` | The object the function was called on |
| `args` | The parameters after the call, `out` parameters included (`nil` for native functions) |
| `result` | The return value. Not passed for functions that return nothing |

Return a non-`nil` value to **replace the return value**; return nothing to leave it. A replacement of the wrong
type is logged as an error and the original value is kept.

```lua
h7.hook_post("MMH7Game.H7CombatArmy.GetKilledCreaturesXP", function(army, args, xp)
    if xp > 0 then return math.floor(xp * 1.5 + 0.5) end
end)
```

Several hooks on one function all run in the order they were added: every pre-hook, then (unless blocked) the
function, then every post-hook. When two post-hooks replace the result, the later one wins and receives the
earlier one's value as `result`.

### h7.unhook

```lua
h7.unhook(id)
```

Removes the hook `id`. Unknown ids are ignored. Hooks are removed automatically when their mod unloads.

## Events and timers

See [Events and timers](events.md) for the list of events and how timers are scheduled.

### h7.on

```lua
h7.on(event, fn) → id
```

Calls `fn(...)` every time `event` fires, with the [event's arguments](events.md#events). Returns the handler's
id. Handlers run in the order they were added. Any event name is accepted, so a misspelt name simply never fires.

```lua
h7.on("map_loaded", function(map) h7.log("Entered " .. map) end)
```

### h7.off

```lua
h7.off(id)
```

Removes the event handler `id`. Unknown ids are ignored.

### h7.after

```lua
h7.after(seconds, fn) → id
```

Calls `fn()` once, `seconds` of game time from now (on the first frame at or after that time). Returns the
timer's id.

```lua
h7.after(5, function() h7.log("5 seconds later") end)
```

### h7.every

```lua
h7.every(seconds, fn) → id
```

Calls `fn()` every `seconds` of game time until cancelled. The first call is `seconds` from now. At most one call
per frame: a timer shorter than a frame runs once per frame. `seconds` of `0` or less makes a one-shot timer,
like [`h7.after`](#h7after).

### h7.cancel

```lua
h7.cancel(id)
```

Cancels the timer `id`. Unknown ids (including timers that already fired) are ignored. A timer may cancel
itself.

```lua
local n, id = 0, nil
id = h7.every(1, function()
    n = n + 1
    if n == 10 then h7.cancel(id) end
end)
```

## Creating objects

See [Creating objects](../API.md#creating-objects) in the guide for how copies interact with the garbage
collector, lazily loaded references, localisation and save games.

### h7.clone

```lua
h7.clone(source, name [, outer [, flags]]) → object, created
```

Creates a copy of `source`: an object of the same class with every property copied from it.

| Parameter | |
|---|---|
| `source` | The object to copy, usually an archetype (a template such as `Creature_Pixie.A_CreaturePixie`) |
| `name` | Name of the new object |
| `outer` | The object or package that contains it. Default: the transient package. Use [`h7.package`](#h7package) for stable paths |
| `flags` | Extra [object flags](#h7flags) to add, e.g. `h7.flags.RootSet` |

| Returns | |
|---|---|
| `object` | The copy |
| `created` | `true` if it was created now; `false` if `outer` already held an object called `name` of the same class, which is returned instead |

The copy keeps the source's `Public`, `Standalone` and `Archetype` flags, so a copy of an archetype is an
archetype too. Returning an existing copy makes mod code safe to run again after a hot reload.

**Errors:** `<path> already exists with another class`; `could not create <class> '<name>': <reason>` (for
example when [`h7.can_create()`](#h7can_create) is `false`).

```lua
local pkg = h7.package("MyMod")
local sprite = h7.clone(h7.find("Creature_Pixie.A_CreaturePixie"), "A_CreatureFrostSprite", pkg, h7.flags.RootSet)
sprite.mHitpoints = 20
```

### h7.new_object

```lua
h7.new_object(class [, options]) → object
```

Creates a new object of `class`. `options` is a table with any of:

| Field | |
|---|---|
| `name` | Object name. Default: a generated unique name |
| `outer` | Containing object or package. Default: the transient package |
| `template` | Object to copy property values from. Default: the class defaults |
| `flags` | [Object flags](#h7flags) (replaces the default `Public + Standalone`) |
| `archetype` | `true` to add the `Archetype` flag |
| `replace` | `true` to reconstruct an existing object with the same name in place (same address, properties reset) instead of failing |

**Errors:** `unknown class '<name>'`; `<path> already exists (pass replace = true to reconstruct it)`;
`could not create <class> '<name>': <reason>`.

```lua
local copy = h7.new_object("H7Creature", { name = "A_MyCreature", outer = h7.package("MyMod"),
                                           template = h7.find("Creature_Pixie.A_CreaturePixie"), archetype = true })
```

### h7.package

```lua
h7.package(name) → package
```

The top-level package called `name`, created if it doesn't exist. Objects inside it have stable paths
(`MyMod.A_CreatureFrostSprite`), which is what save games store.

**Errors:** `could not create package '<name>': <reason>`.

### h7.name

```lua
h7.name(str) → str
```

Adds `str` to the engine's name table (if it isn't there yet) and returns it. Writing a `name` property does this
for you; call it yourself when a name must exist before the game looks it up.

**Errors:** `could not create name '<str>'`.

### h7.can_create

```lua
h7.can_create() → boolean
```

`true` when the engine found and verified the game functions object creation needs. When `false`, the reason is
in the log and [`h7.clone`](#h7clone), [`h7.new_object`](#h7new_object), [`h7.package`](#h7package) (for a new
package) and [`h7.name`](#h7name) (for a new name) fail.

### h7.flags

```lua
h7.flags.Public | .Standalone | .Transient | .Archetype | .RootSet → integer
```

Object flags for [`h7.clone`](#h7clone) and [`h7.new_object`](#h7new_object). Combine them with `|`.

| Flag | Value | Meaning |
|---|---|---|
| `Public` | `0x0000000400000000` | Visible outside its package |
| `Standalone` | `0x0008000000000000` | Kept while its package is loaded, even when unreferenced |
| `Transient` | `0x0000400000000000` | Never saved |
| `Archetype` | `0x0000000000000400` | A template other objects are created from |
| `RootSet` | `0x0000000000004000` | Never garbage collected |

## Mods

### h7.mods

```lua
h7.mods() → { { name, version, author, description, category, enabled, loaded, hidden, settings }, ... }
```

Every installed mod, in load order.

| Field | |
|---|---|
| `name`, `version`, `author`, `description`, `category` | From the [manifest](mod.md#manifest) (empty strings when not set) |
| `enabled` | Whether the mod is turned on (manifest `enabled`, overridden by the player's choice in `H7ModEngine.ini`) |
| `loaded` | Whether it is running. `enabled` but not `loaded` means it failed to load: see the log |
| `hidden` | Manifest `hidden`: not listed in the Mods menu |
| `settings` | How many [settings](mod.md#settings) it declares |

### h7.set_mod_enabled

```lua
h7.set_mod_enabled(name, on)
```

Turns the mod `name` on (`on` truthy) or off. The choice is saved in `H7ModEngine.ini` and the mod loads or
unloads at the start of the next frame, after which [`mod_toggled`](events.md#mod_toggled) fires. A mod may
disable itself.

**Errors:** `unknown mod '<name>'`.

### h7.mod_settings

```lua
h7.mod_settings(name) → { setting, ... }
```

The settings the mod `name` declares, in manifest order, each with its current value:

| Field | |
|---|---|
| `key`, `label`, `description` | As declared (`label` defaults to `key`) |
| `type` | `"bool"`, `"number"`, `"choice"` or `"text"` |
| `value` | Current value |
| `default` | Declared default |
| `min`, `max`, `step` | Numbers only, when declared |
| `options` | Choices only: the allowed values |
| `reload` | Whether changing it restarts the mod |
| `control` | Numbers only, when declared: `"slider"`, `"input"` or `"arrows"` |

**Errors:** `unknown mod '<name>'`.

### h7.set_mod_setting

```lua
h7.set_mod_setting(name, key, value) → stored value
```

Changes a setting of mod `name`, exactly like the Mods menu does: the value is validated (numbers are clamped
to `min`..`max` and snapped to `step`), saved in `H7ModEngine.ini`, and
[`setting_changed`](events.md#setting_changed) fires if it changed. Returns the value as stored. A mod changes
its own settings with [`mod.settings.key = value`](mod.md#modsettings).

**Errors:** `unknown mod '<name>'`; `mod <name> has no setting '<key>'`; `invalid value for <name>.<key> (<type>)`
(e.g. a string for a number, or a value not in `options`).

### h7.reload

```lua
h7.reload()
```

At the start of the next frame, unloads every mod, scans the `mods` folder again (picking up new mod folders) and
loads every enabled mod; then [`mods_loaded`](events.md#mods_loaded) fires.

## Console

### h7.exec

```lua
h7.exec(command) → string
```

Runs an Unreal console command through the local player controller (`PlayerController.ConsoleCommand`) and
returns its output. Which commands work depends on the game's (shipping) build.

**Errors:** `no PlayerController exists yet` (very early during startup).
